# AI 작업 세션 — 2026-05-15

## 작업 요약

도메인별 HTTP 테스트 파일(`http/` 디렉토리)을 생성하고 README.md에 사용 방법을 정리했다.

## 프롬프트 & 시도한 내용

| # | 프롬프트 | 시도한 내용 |
|---|----------|-------------|
| 1 | 각 API를 테스트할 수 있도록 http 파일 만들어줘, 각 도메인별로 | Explore 에이전트로 전체 컨트롤러·DTO 분석 후 `http/` 디렉토리에 6개 `.http` 파일과 환경 변수 파일 생성. 로그인 요청에 `> {% client.global.set("token", ...) %}` 핸들러 추가해 JWT 자동 저장 |
| 2 | point 충전도 http 추가해줘 | 관리자 MVC 엔드포인트(`/admin/members/{id}/charge-point`)만 존재함을 확인 후 `http/member.http` 신규 생성 |
| 3 | 포인트를 http로 충전할 방법없나 | `MemberController`·`AdminMemberController` 코드 확인 — REST API 미존재, MVC 방식만 있음을 확인 (추가 구현 없이 현황 설명) |
| 4 | 이 http 파일들도 README.md에 정리해줘 | README.md의 AI 도구 활용 기록 앞에 **HTTP 테스트 파일** 섹션 추가 — 파일 목록 표 + 4단계 사용 방법 기술 |

## 메모

- 포인트 충전 REST API(`/api/members/me/charge-point` 등)가 없어서 HTTP 파일로 JSON 응답을 받을 수 없는 상태. 필요하면 `MemberController`에 별도 엔드포인트 추가 필요.
- `http-client.env.json`의 `local` 환경 선택이 필요 — IntelliJ 편집기 우측 상단 드롭다운에서 선택
