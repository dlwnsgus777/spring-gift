## 메모

- **MockMvc + @Transactional**: MockMvc 요청은 별도 스레드에서 처리되므로 테스트의 @Transactional 롤백이 적용되지 않는다. 컨트롤러 테스트는 UUID로 데이터 충돌을 방지하고, 서비스 테스트는 @Transactional로 격리한다.
- **Testcontainers 싱글턴**: @Container static을 부모 클래스에 두면 각 테스트 클래스 종료 시 컨테이너가 내려간다. static block에서 직접 start()하면 JVM 종료 시까지 유지된다.
- **Service → Domain 객체 반환**: Service가 Response DTO를 반환하면 표현 계층(HTTP)에 종속된다. 도메인 객체를 반환하고 Controller에서 변환하는 것이 계층 책임에 맞다.
