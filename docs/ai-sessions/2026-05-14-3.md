## 메모

- Fixture 기본값에 UUID를 필드 초기화식에서 생성(`"카테고리_" + UUIDGenerator.uuid()`)하면 `new Builder()` 호출마다 다른 UUID가 만들어져 테스트 격리가 자연스럽게 보장된다.
- `notification → order` 단방향 의존: `gift.order`는 `gift.notification`을 전혀 알지 못하게 됐다. 알림 발송이 주문 도메인 관심사가 아님을 패키지 구조로 표현.
- `AuthenticationResolver`는 `AuthService.extractMember()`와 동일 로직이었고 어디서도 호출되지 않았다. Spring 4.3부터 단일 생성자는 `@Autowired` 없이 자동 주입된다.
