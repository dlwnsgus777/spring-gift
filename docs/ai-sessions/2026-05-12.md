## 메모

- **Red = 런타임 실패**: 컴파일 에러는 Red가 아님. 컴파일 에러 시 `throw new UnsupportedOperationException("Not implemented yet")`으로 스켈레톤 먼저 생성 후 테스트 실행해서 런타임 실패 확인.
- **"카카오" 규칙 위치**: Product 생성자는 포맷(길이·문자셋)만 검사(`allowKakao=true`). "카카오" 컨텍스트 의존 규칙은 `ProductCommandService.validateKakao()`에서 처리. Admin 경로는 createForAdmin/updateForAdmin으로 우회.
- **AdminProductController의 ProductNameValidator 호출 유지**: 도메인 검증이 아닌 폼 재출력 목적(UI). 제거하지 않음.
- **위시 있는 상품 삭제 버그**: `wish.product_id` FK에 ON DELETE CASCADE 없어서 위시가 있는 상품 삭제 시 DB FK 제약 위반. 8단계에서 처리 예정.
