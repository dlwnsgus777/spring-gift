## 메모

- `platform()` 은 BOM 전용 — 일반 JAR 아티팩트에 쓰면 잘못된 사용
- Spring Boot 의존성 관리(`io.spring.dependency-management`)가 있으면 Testcontainers BOM 불필요
- `@Container static` 필드 → JVM 당 컨테이너 1개 재사용. `static` 빠지면 클래스마다 새 컨테이너 기동
- commons-compress 오버라이드: override 있는 상태에서 검증하면 틀린 결론 나올 수 있음 — 제거 후 직접 확인 필요
