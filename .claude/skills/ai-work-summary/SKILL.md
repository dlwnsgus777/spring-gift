## 목적

AI와 협업한 작업 세션을 나중에 돌아볼 수 있도록 문서화한다.
무엇을 요청했고, 어떤 시도가 있었고, 실제로 무엇이 바뀌었는지를 기록으로 남긴다.

## 절차

### 1. 대화 컨텍스트에서 정보 추출

현재 대화 히스토리를 처음부터 돌아보며 다음을 파악한다:

- **핵심 프롬프트**: 작업의 흐름을 만든 사용자 요청들 (모든 메시지가 아닌, 의미 있는 단위로 묶어 정리)
- **시도한 내용**: 각 요청에 대해 AI가 어떤 접근을 했는지 (방향 전환이나 수정 요청이 있었다면 함께 기록)
- **변경된 파일**: 대화 중 실제로 생성·수정된 파일 목록과 변경 내용

### 3. 세션 문서 생성

파일 경로: `docs/ai-sessions/YYYY-MM-DD.md`
- `docs/ai-sessions/` 디렉토리가 없으면 생성한다
- 같은 날 여러 세션이면 `2026-05-07-2.md`처럼 번호를 붙인다

템플릿 파일 `.claude/skills/ai-work-summary/assets/session-template.md`를 읽어 사용한다.
`{{DATE}}`를 오늘 날짜로 치환하고, 수집한 내용으로 각 섹션을 채운다.

### 4. README.md AI 도구 활용 섹션 업데이트

`README.md`의 `## AI 도구 활용 기록` 표 마지막에 새 행을 추가한다.
기존 행은 절대 수정하거나 덮어쓰지 않는다.

추가할 행 형식:
```
| (핵심 프롬프트 한 줄 요약) | (시도한 내용 한 줄 요약) | [세션 문서](docs/ai-sessions/YYYY-MM-DD.md) |
```

여러 프롬프트가 있으면 가장 대표적인 것 하나만 표에 넣는다.
세부 내용은 링크된 세션 문서에서 확인할 수 있다.

## 완료 후

생성된 파일 경로 두 가지를 사용자에게 알린다:
- 세션 문서: `docs/ai-sessions/YYYY-MM-DD.md`
- README.md 업데이트 위치
